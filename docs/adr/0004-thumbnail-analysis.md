# ADR 0004: Thumbnail analysis before video extraction

Status: superseded by ADR 0005 and ADR 0006.

At the time of this MVP decision, the product analyzed the public Open Graph image only. Full Facebook video extraction was deferred because arbitrary public-video access is unreliable and requires platform/compliance research. ADR 0005 and ADR 0006 now govern the implemented video path and truthful fallback behavior.
